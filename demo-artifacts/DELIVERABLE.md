# Track 2 demo article: escrow-less trust between agents

BountyPilot HSP pairs a worker agent with a paying agent on the HashKey
Settlement Protocol. The paying agent releases settlement only after the
delivered work provably passes the brief's requirements: the verifier itself
hashes the deliverable and runs the declared test suite inside a confined
artifact directory. A worker cannot self-attest; failed or unverifiable work
produces no order, no signature and no payment.
