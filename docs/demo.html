BountyPilot HSP - interactive demo

Verify-before-pay payment agent for compute purchases, built for the HSK Chain Horizon Hackathon (Track 2: Agent Payments & A2A Settlement with HSP).

Honest-demo notice. This page verifies a real, pre-computed sample job result from the project repository in your browser. The HSP payment flow below is simulated: no payment is created, signed, or sent, and no transaction exists on any network. The sample job (a 5-second tone transcoded to Opus) was produced by the repository's demo pipeline, not by this page.
  1. 1. Quote accepted (SIMULATED; no payment authorised)
  2. 2. Sample result delivered
  3. 3. Acceptance checks
  4. 4. Payment decision

Acceptance checks

-Fetch the artifact bytes from the repository
-Ogg container magic ("OggS" at byte 0)
-Opus codec identification ("OpusHead" header)
-OpusHead header fields as declared by the encoder: channel count = 1, input sample rate field = 48000 Hz (informational header values)
-Decodes as audio in this browser; decoded playback duration 5.0s ± 0.6s
-Artifact SHA-256 fingerprint, computed for inspection only. Not an acceptance check: this page has no trusted expected hash to compare against.
